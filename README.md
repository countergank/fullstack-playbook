# Full Stack Developer — Knowledge Playbook

> Ruta de formación profesional para desarrollo web full stack.
> Los tópicos están ordenados de fundacional a avanzado. Cada uno se detalla con los conceptos específicos a dominar.

---

## 1. Fundamentos de la Web

Arquitectura cliente-servidor, protocolo HTTP (métodos, headers, status codes), DNS, navegadores, REST, CORS, HTTPS/TLS.

## 2. Fundamentos de Programación

Algoritmos, estructuras de datos, control de versiones (Git), terminal (incluye WSL), SSH, Docker, resolución de problemas, debugging.

## 3. IA & Desarrollo Asistido

LLMs, prompt engineering, contexto y ventanas de contexto, SDD (Spec-Driven Development), Gentle AI, Engram, OpenCode, code review asistido, ética y limitaciones, ecosistema de herramientas.

## 4. Backend Core

Node.js runtime, APIs REST, GraphQL, autenticación/autorización, middlewares, manejo de errores, validación, file upload.

## 5. Frameworks & Herramientas Backend

Express, NestJS o Fastify, Prisma (SQL), Mongoose (NoSQL), logging, jobs y queues, WebSockets, server-sent events.

## 6. Bases de Datos & Persistencia

PostgreSQL, MongoDB, modelado de datos, migrations, caching (Redis), estrategias de query, índices, backups.

## 7. Frontend Core

HTML semántico, CSS moderno (Flexbox, Grid, responsive), JavaScript, TypeScript, DOM, accesibilidad, Web APIs.

## 8. Frameworks & Herramientas Frontend

React, manejo de estado, routing, Vite (bundler y dev server), Vitest (testing de componentes), Next.js, sistemas de estilos (CSS Modules, Tailwind, styled-components).

## 9. DevOps & Deployment

Docker, CI/CD, cloud (AWS, Vercel, Railway), entornos, monitoreo, logging centralizado, secrets management.

## 10. Testing

Unit tests, integration tests, e2e, TDD, mocking, stubbing, coverage, testing libraries (Vitest, Jest, Playwright).

## 11. Arquitectura de Software

Clean Architecture, Hexagonal, SOLID, patrones de diseño, separación de concerns, monolitos vs microservicios, DDD intro.

## 12. Seguridad

OWASP Top 10, CORS, CSRF, XSS, SQL injection, JWT, hashing (bcrypt, argon2), secret management, supply chain.

## 13. Performance & Optimización

Web Vitals (LCP, FID/INP, CLS), lazy loading, code splitting, bundle analysis, caching strategies, database indexing, N+1 problem, paginación.

## 14. Prácticas Profesionales

Agile/Scrum, code review, documentación técnica, comunicación efectiva, toma de requerimientos, estimación, trabajo en equipo.
